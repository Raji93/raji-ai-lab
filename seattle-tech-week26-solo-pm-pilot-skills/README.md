## ✨ Why this repo exists

This playbook is designed for **solo Product Managers** who want a clearer path from early discovery to pilot execution.

It helps you move from:
- 🌀 messy discovery notes
- 🎯 a scoped pilot plan
- 🛠️ a lightweight prototype approach
- ✅ feedback-driven decisions you can defend

The goal is not to replace product judgment. It is to make that judgment sharper, faster, and easier to act on.

## 🔄 The core loop
<img width="1536" height="1024" alt="Core Loop" src="https://github.com/user-attachments/assets/89f7d0bc-d37d-4024-b517-9cd46b1dbcd4" />

**Scope → Build → Iterate**

This is the operating rhythm for a pilot:

- **Scope**: Turn rough discovery into a focused pilot plan  
- **Build**: Create a lightweight plan, tool map, and prototype path  
- **Iterate**: Gather feedback, evaluate, and decide whether to ship, pause, or hand off

## 🧩 What’s inside

This repo includes:

- ****Three skills** for the full Pilot journey**.
- **Three paste-ready prompt versions**.
- **A simple playbook for using them across different AI platforms**.

### Skill map

| Skill | Purpose |
|---|---|
| Scope | Turn messy discovery notes into a scoped pilot plan |
| Build | Turn that plan into a build path, tool map, and prototype approach |
| Iterate | Refine based on feedback, evaluate the idea, and decide next steps |

## 🚀 Quick start

If you want to use this right away:

1. Choose one of the three skills
2. Paste the matching prompt into your chat or load the skill in a supported platform
3. Share your rough notes, discovery summary, or pilot idea
4. Use the output as a working artifact for your next step

These skills help structure your thinking, but they do not replace real product work.

The point is to make that work easier to execute and easier to communicate.
