# Your access checklist

*Keys You Shouldn't Hand Your Agent · Seattle AI Week 2026* · [Printable PDF](./access-checklist.pdf)

## 1 · Before you sign up (Vet)

- [ ] I know who makes it and how to contact them
- [ ] I read what it keeps, for how long, and whether it trains on my data
- [ ] I wrote down what my task needs before opening the consent screen
- [ ] It can work with read-only access to start
- [ ] It pays with one-time or limited cards, never my saved card
- [ ] It has approvals, "Allow once", an activity log and a stop button
- [ ] I can delete its memory and my account, not just disconnect
- [ ] If I host it myself, it isn't reachable from the open internet

## 2 · At the consent screen (Grant)

- [ ] It asks for only the apps the intro screen named
- [ ] I didn't tap "Select all"
- [ ] I unchecked send, delete and full-Drive access my task doesn't need
- [ ] I chose "Allow once" over "Allow always"
- [ ] I turned approvals on right after connecting

## 3 · Always ask me first

- [ ] Sending a message or email
- [ ] Spending any money
- [ ] Deleting anything
- [ ] Sharing files or location
- [ ] Changing passwords or security

## 4 · Never hand over

- Password manager
- Bank and brokerage logins
- 2FA and recovery codes
- ID documents (passport, driver's license, SSN)
- Crypto seed phrases
- Admin or production access at work

## 5 · Every month (Audit)

- [ ] Google: [myaccount.google.com/linkedapps](https://myaccount.google.com/linkedapps) → View by **Access to › Any account access** → remove what I don't use
- [ ] Microsoft: [microsoft.com/consent](https://microsoft.com/consent) → remove unused apps
- [ ] Inside each agent: downgrade connectors to read-only
- [ ] Turn "Always allow" into "Ask first" for sending, spending, deleting and sharing
- [ ] Make it forget: reset memory and activity, not just access
